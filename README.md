# REC 2001 student directory

Branch-wise working directory for REC Rourkela Class of 2001.

169 known names across 9 branches as of 28 October 2026. **Incomplete: not the full batch roster or an official college roll.** No registration or attendance status is implied.

Only names and branches are public. Contact, payment, room, preference and travel details are omitted.

Branch strengths shown are organiser-supplied estimates totalling 300, not independently verified roll counts.

Files: `index.html` is a self-contained searchable HTML page; `directory.json` holds names and branches only.
